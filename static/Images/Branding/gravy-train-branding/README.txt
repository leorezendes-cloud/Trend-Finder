GRAVY TRAIN BRANDING

Each brand folder contains:
- full.png: approved source artwork, cropped to its own panel without the bottom menu. Original pixels retained. These are illustrated landing-page logos, with opaque backgrounds.
- nav.png: separately generated streamlined horizontal logo, transparent PNG. Best on dark headers. Keep aspect ratio; use about 48-64px tall. Dungeon text benefits from a wider display.
- icon.png: transparent 512px square brand icon; additional PNG sizes supplied.

favicon.ico is the main Gravy Train favicon with 16, 32, 48, 64, 128 and 256px entries.

The Plug full artwork preserves the boss office, cash and cigar smoke with no tagline. Dungeon preserves the silver/red title and original NFL checklist, with no blood drips.

Compact artwork created with the built-in image generation tool using the approved image as reference; exact prompts are included in generation-prompts.json. Compact versions are adaptations; the full artwork is preserved from the supplied source.
