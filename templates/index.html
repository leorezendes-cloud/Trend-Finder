How the grouped search works

Game time: morning before noon, day from noon to 7 PM, night from 7 PM onward, using CSV times.

Rest: less than 7 days, exactly 7 days, or more than 7 days. Automatic combinations include all totals; the Total Line field remains available for a manual exact-total filter.

Week, temperature, and wind use bands. Automatic searches consider all eligible features; spread and total are only applied when you select their manual filters. Teams, underdog quarterbacks, coaches, stadiums, referees, roofs, surfaces, weekdays, game types, and division games use their CSV categories. Dates are grouped by month.

Quarterback combinations use only the underdog’s quarterback, whether home or away. Home and away quarterback names remain available as manual filters.

Automatic combinations must match a game context in the newest CSV season, keeping older quarterbacks, coaches, teams, stadiums, and referees out of discovery. This uses CSV activity rather than live roster status. Historical names remain available in manual filters.

Missing values do not create categories. Groups below the minimum sample are removed. The search checks up to three features together and expands the strongest 150 candidates at each step.

The upcoming flag requires every condition and manual filter to match a known, unstarted CSV game within seven days. Missing game details cannot establish a match.

Final scores, results, overtime, and game IDs are manual filters only. Automatic searches use pregame information.
